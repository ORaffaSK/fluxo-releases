# Fluxo — Instaladores

Esta página reúne apenas os instaladores do **Fluxo**, o controle financeiro para Windows.
O código-fonte não fica aqui.

## Como instalar
1. Abra a aba **Releases** (à direita desta página) e escolha a versão mais recente.
2. Baixe o arquivo `Fluxo-Instalador-X.Y.Z.exe` e execute.
3. Se o Windows mostrar "Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**. O instalador ainda não é assinado digitalmente.

## Atualizações
O Fluxo verifica esta página sozinho e avisa quando houver versão nova. Seus dados ficam apenas no seu computador, criptografados.
